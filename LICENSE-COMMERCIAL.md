## When you need a commercial license

You need a commercial license if **any** of the following are true:

- You include SVCS source code or compiled binaries in a closed-source product
  that you distribute to customers, and you do not want to release the source
  code of your product under AGPL-3.0.
- You run SVCS or a modified version of SVCS as part of a network service
  (SaaS, hosted API, mobile backend, etc.) and you do not want to release the
  source code of that service under AGPL-3.0.
- You sell a hardware appliance, plugin, or extension that bundles SVCS, and
  you cannot or will not ship the corresponding source code to customers.

## When you do NOT need a commercial license

The AGPL-3.0 open-source license is sufficient if:

- You are an individual using SVCS for personal use (compressing your own
  video library, self-hosted Jellyfin or Plex setup, hobby projects).
- You are a researcher, student, or academic.
- You are an open-source project that is willing to release its own code
  under AGPL-3.0.
- You run SVCS internally inside your company and do not redistribute it.

Email **kdhaiti2024@fau.edu** (subject line: "SVCS Commercial License").

- Your company name and use case
- Estimated number of installs or end users
- Whether you need a per-install, per-seat, per-instance, or unlimited
  enterprise license
