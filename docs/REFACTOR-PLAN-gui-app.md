# Refactor Plan: `src/gui/app.py` → Blueprint + Services Layout

Authored 2026-05-14 against `app` branch. Generated by the Plan agent in
response to audit item: split the 3800-line `gui/app.py` monolith.

This plan is **non-binding** — adjust as the migration uncovers things
the static read missed.

---

## 0. Hard constraints (non-negotiables)

- `from gui.app import app` must keep working. `run_gui.py:262` and
  `tests/test_gui_api.py:34` both rely on it.
- `gui.app` module must continue to expose these private names —
  `tests/test_gui_api.py` reaches into all of them via `gui_module.*`:
  `_state_lock`, `_status`, `_pipeline_thread`, `_stop_event`,
  `_run_pipeline_thread`, `_demo_lock`, `_demo_state`, `_hls_lock`,
  `_hls_state`, `_hls_frame_ts_dq`, `_hls_segment_latencies`,
  `_default_output_dir`, `_CLOUD_SUBFOLDER`.
  The cleanest way is to re-export from the new modules so old test
  code keeps working without churn.
- The atexit handler (`_write_shutdown_log`) must still fire; it owns
  `_file_handler.flush()`.
- PyInstaller spec at `installer/svcs.spec` needs new hiddenimports for
  every new submodule.

## 4. Migration order (each step must leave tests green)

1. Extract **`state.py`** — pure data. Re-export the names from `app.py`.
2. Extract **`logging_setup.py`** — handlers + atexit. Verify shutdown
   marker still lands in `svcs.log`.
3. Extract **`services/path_safety.py`** and **`services/cloud_detection.py`**.
4. Extract **`services/gui_state_persist.py`** and **`services/db_helpers.py`**.
5. Extract **`services/cpu_sampler.py`** — convert import-time
   `_bg_hw_thread` to an explicit `start_hw_sampler()` called from
   `create_app()`.
6. Extract **`services/rtsp.py`**.
7. Extract **`services/demo_runner.py`** and **`services/hls_runner.py`**.
8. Extract **`services/pipeline_runner.py`** (most threading, do last).
9. Carve out blueprints smallest first: ui → sse → metrics → presets →
   encryption → plates → queries → rtsp → demo → hls → files → pipeline.
10. Finalize re-exports in `gui/app.py`.
11. Update `installer/svcs.spec` hiddenimports for every new submodule.

## 5. Risk list

- **Re-export drift.** 15+ private names. Mitigation: write a
  `test_gui_state_reexports.py` that asserts each name resolves via
  `gui.app`.
- **Circular imports.** Direction must be one-way: services may import
  state + logging_setup, never the reverse. Blueprints import services.
  `gui.app` imports blueprints. Nothing imports `gui.app`.
- **SSE generator closure.** `api_logs()`'s `generate()` closes over
  `_log_queue`, `_log_history`, etc. After extraction, import these at
  the top of `sse_bp.py` so the closure binds to module-level names.
- **Atexit ordering.** Keep `_file_handler` and `_write_shutdown_log`
  in the same module.
- **`_bg_hw_thread` startup at import.** Move to an explicit start
  function called from `create_app()`.
- **`global _pipeline_thread`.** After moving into a service module,
  tests that mutate `gui_module._pipeline_thread = None` will hit a
  stale local copy. Fix with a module-level `__getattr__` /
  `__setattr__` on `gui.app` that forwards to the service module.
- **PyInstaller hidden imports.** List every new submodule explicitly.

## 6. Test strategy

Existing 102 tests are the primary safety net. Run after every commit.

New tests to add alongside the refactor:

- `tests/test_gui_blueprint_registration.py` — asserts route count and
  each expected endpoint exists.
- `tests/test_gui_state_reexports.py` — for every re-exported name,
  asserts `hasattr(gui.app, name)` and that mutation round-trips
  between `gui.app` and `gui.state`.
- `tests/test_gui_routes_resolve.py` — every URL pattern resolves via
  `app.url_map.bind(...).match(...)`.
- `tests/test_gui_sse_smoke.py` — push a log record, GET `/api/logs`,
  assert SSE line received.
- `tests/test_atexit_shutdown_log.py` — direct call to
  `_write_shutdown_log()`, then tail of log file shows the marker.
