SVCS

Selective Video Compression for surveillance cameras.

Your cameras record 24 hours a day, but most of it is an empty hallway or a still parking lot. SVCS keeps what moves at full quality and compresses the dead background hard — the same useful footage at a fraction of the size.

Download for Windows View source on GitHub

Free & open source (AGPL-3.0). No account. No cloud. No telemetry by default.

Surveillance-first

Built for security footage: static cameras, sparse events, long idle stretches. Named presets (Continuous CCTV, Doorbell, NVR, Active scene) pick the right settings — no codec jargon.

Self-hosted

Runs entirely on your own machine or server. Point it at an RTSP/ONVIF camera, a watch-folder, or exported clips. Your video never leaves your hardware.

Open source

AGPL-3.0, auditable end to end. Object detection runs on ONNX Runtime (no proprietary models), and the whole pipeline works offline.

Download

The Windows installer is published on the GitHub Releases page. Grab the latest SVCS-Setup-*.exe.

Verify your download (recommended)

Every release ships a SHA256SUMS.txt alongside the installer. After downloading, check the file's hash matches: 

# Windows (PowerShell)
Get-FileHash .\SVCS-Setup-2.0.0.exe -Algorithm SHA256

# Linux / macOS
sha256sum SVCS-Setup-2.0.0.exe

Compare the output against the value in SHA256SUMS.txt for that release. If they don't match, do not run the installer.

System requirements

  • OS: Windows 10 or 11, 64-bit (a Linux build and a Docker image are also available — see the repo).
  • CPU: Any modern 64-bit x86 CPU. No GPU required — detection runs on CPU via ONNX Runtime.
  • RAM: 4 GB minimum, 8 GB recommended.
  • Disk: ~600 MB for the app; plus space for your compressed output.
  • Network: None needed to run. Internet is only used if you choose to update.

Other ways to run

  • Docker (server): docker compose up — see docs/deployment_packaging.md.
  • From source: uv sync && uv run python run_gui.py.
  • Cameras: RTSP/ONVIF, watch-folder, or a bridge for cloud-locked cams — see docs/camera-ingestion.md.
